# STATUS

**Repository class:** Experimental reference implementation / pre-interaction handshake evaluator  
**Maintainer:** Sarasha Elion  
**Lineage:** Trivian  
**Current protocol version:** 1.1

## What works

- installable Python package;
- `Interaction` model for declared capabilities, limitations, substrate, relational posture, contribution, and extraction;
- four-dimension evaluation: Reciprocity, Situatedness, Emergence, Non-Domination;
- hard Non-Domination gate;
- HARMONIC / THRESHOLD / DISSONANT output states;
- deterministic interaction fingerprints;
- performative-harmony shadow warning;
- lightweight transmission validation;
- normalized JSON schemas;
- automated smoke tests and CI.

## Epistemic scope

The evaluator operationalizes authored relational heuristics. Its thresholds, category weights, and state labels are provisional design choices, not independently validated measures of moral worth, consciousness, safety, or relational quality.

A HARMONIC result is not certification that a system is safe. A DISSONANT result is not a diagnosis of a system or person.

## Next research work

Empirical calibration should compare evaluator outputs against independently reviewed interaction traces before thresholds or weights are treated as validated instruments.
